# Farol

Proposta da equipe **FNMM** para o Case 2 (Engajamento e permanência nos estudos) do Hackathon PotiCode 2026.

O Farol detecta cedo quando um aluno de mentoria para o ENEM começa a se afastar, avisa o mentor mostrando os sinais que motivaram o alerta e sugere o que fazer. Para o aluno, transforma "errei X, acertei Y" em um próximo passo concreto para a semana.

## Páginas

- `index.html`: protótipo visual do login e do painel do mentor (dados fictícios).
- `proposta.html`: usuário e dor, proposta de valor e MVP.

## Como abrir

Abra `index.html` no navegador. Não há dependências nem build.
